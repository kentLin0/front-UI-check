# front-UI-check

An open-source Codex skill for reconstructing Figma application screens in frontend projects and verifying the real running page through screenshot-based review.

## Skill

- [`figma-ui-reconstruction`](SKILL.md)

The skill triggers when a user asks to reconstruct, implement, reproduce, align, or pixel-match a Figma design. It is framework- and component-library-independent and includes modular implementation guidance, runtime capture checks, adversarial visual review, and disputed-finding verification.

## Installation

Clone or copy this repository into a Codex skills directory while preserving `SKILL.md`, `agents/`, and `references/` at the repository root.
